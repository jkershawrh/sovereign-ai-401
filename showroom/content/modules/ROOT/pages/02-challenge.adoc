= 2. Issue a workload-bound challenge

Declare the expected namespace, service account, immutable image digest, and
requested protected resource. Issue a unique nonce with a short expiration.

The challenge prevents an old attestation result from being replayed for a new
decision. Confirm that the operation contract binds the nonce to the exact
workload identity and consumes it only once.

Run the replay fixture after the allowed rehearsal. The second request must be
`REFUSE` with `REPLAYED_CHALLENGE`.
