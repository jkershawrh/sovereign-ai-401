= 3. Reject a false LIVE attestation claim (10 minutes)

== Show

The scenario list declares `liveTdxObserved: false`. That provenance travels
with every decision.

== Learn

Changing a label cannot turn a synthetic fixture into a cryptographic quote.
The service must reject the claim before resource policy or inference.

== Do

[source,bash,role="execute"]
----
curl -fsS "$TRUST_URL/api/v1/scenarios" \
  | tee /tmp/northstar-scenarios.json | python3 -m json.tool
----

[source,bash,role="execute"]
----
curl -fsS -X POST "$TRUST_URL/api/v1/operate" \
  -H 'content-type: application/json' -d '{"scenario":"simulated_live_claim"}' \
  | tee /tmp/northstar-false-live.json | python3 -m json.tool
----

== Prove

Confirm `sourceState` remains `REHEARSAL`, the reason is `FALSE_LIVE_CLAIM`,
and no protected key or model was used.
