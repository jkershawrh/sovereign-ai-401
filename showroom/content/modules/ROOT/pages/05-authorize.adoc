= 5. Authorize one bounded resource (10 minutes)

== Show

Northstar policy matches one approved workload identity to one named resource.
The allowed rehearsal returns a digest receipt only.

== Learn

Appraisal answers whether evidence matches. Resource policy separately answers
whether that identity may request that resource. A KBS outage cannot fall back
to an environment secret.

== Do

[source,bash,role="execute"]
----
curl -fsS -X POST "$TRUST_URL/api/v1/reset" >/dev/null
curl -fsS -X POST "$TRUST_URL/api/v1/operate" \
  -H 'content-type: application/json' -d '{"scenario":"authorized"}' \
  | tee /tmp/northstar-resource.json | python3 -m json.tool
----

[source,bash,role="execute"]
----
curl -fsS -X POST "$TRUST_URL/api/v1/operate" \
  -H 'content-type: application/json' -d '{"scenario":"kbs_unavailable"}' \
  | tee /tmp/northstar-kbs-offline.json | python3 -m json.tool
----

== Prove

The allowed record contains `SYNTHETIC_RECEIPT_ONLY` and
`keyMaterialReleased: false`. The unavailable KBS returns `ABSTAIN`.
