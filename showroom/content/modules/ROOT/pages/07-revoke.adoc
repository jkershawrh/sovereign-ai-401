= 7. Revoke trust at request time (10 minutes)

== Show

Trust is not permanent. A human-approved reference-value change must affect the
next matching request.

== Learn

Revocation is meaningful only when the same measurement that previously matched
is denied immediately and the decision remains traceable.

== Do

[source,bash,role="execute"]
----
curl -fsS -X POST "$TRUST_URL/api/v1/reset" >/dev/null
curl -fsS -X POST "$TRUST_URL/api/v1/revoke" \
  | tee /tmp/northstar-revocation.json | python3 -m json.tool
----

[source,bash,role="execute"]
----
curl -fsS -X POST "$TRUST_URL/api/v1/operate" \
  -H 'content-type: application/json' -d '{"scenario":"authorized"}' \
  | tee /tmp/northstar-after-revoke.json | python3 -m json.tool
----

== Prove

The next decision is `REFUSE` with `MEASUREMENT_REVOKED`. The lab does not
change production reference values, promote policy, or self-remediate.
